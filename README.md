# Análise de Sentimento de Resenhas com LLM

Projeto de estudo em Inteligência Artificial aplicada, utilizando modelos de linguagem para análise de sentimento de resenhas textuais.

## Descrição
O projeto realiza:
- Leitura de um arquivo `.txt` contendo resenhas
- Envio das resenhas a um modelo de linguagem via API (Groq)
- Extração estruturada das informações em formato JSON
- Conversão para estruturas Python
- Contagem de avaliações positivas, negativas e neutras

## Tecnologias utilizadas
- Python
- Jupyter Notebook
- LLM via API (Groq)
- Manipulação de dados com listas e dicionários
